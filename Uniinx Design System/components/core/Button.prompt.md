Button is the all-purpose CTA used across the Uniinx storefront — a graphite pill for primary actions ("Buy it →") and a lighter mist-gray tone for secondary actions ("New Arrivals").

```jsx
<Button tone="dark" shape="pill">Buy it →</Button>
<Button tone="light" shape="pill">New Arrivals</Button>
```

Variants:
- `tone`: `dark` (graphite), `light` (mist gray, secondary), or `accent` (Kalamkari madder-red — primary purchase CTA, v3 palette).
- `shape`: `pill` (rounded 17px, default storefront treatment) or `capsule` (fully round).
- `font`: `marcellus` (tracked caps) — the only font variant currently defined.
